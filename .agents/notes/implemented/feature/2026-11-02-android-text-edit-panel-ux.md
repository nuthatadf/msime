# Agent Note: Android 文本编辑面板精简侧栏与无缝方向区

Status: implemented

## Problem

文本编辑面板的选行、行边界和独立符号键挤占主要移动与剪贴操作的空间，分散的键帽也使中央区域缺少整体感。精简常驻动作后，需要让方向、选择、文档边界和侧栏形成稳定分组，同时保留用户已有的排序数据与编辑器行为。

## Decision

默认左列从上到下为复制、剪切、粘贴、全选；右列为退格、数字键盘、空格、换行。中央左右方向键跨前三行，中列为上、开始选择、下；末排文首、文尾各占一半。十五项编辑操作同屏可达，不使用滚动列。选行、行首尾和独立符号键不生成可见控件，旧动作身份与编辑器适配保留；换行长按仍进入符号面板。

返回、文本编辑标题、撤销与重做共用一行，覆盖普通工具栏，不增加键盘总高。返回始终回主键盘，保留编辑器光标和选区，清除面板选择开关，不依赖此前打开的面板。底栏两侧保留输入法切换和剪贴板入口，不常驻提示文字；最近复制可用时复用原预览、粘贴、关闭及已配置的快捷操作，不移动中央网格。

方向键使用描边尖括号，文首尾使用尖括号加竖线，通过矢量旋转统一方向，避免字体基线与裁切差异。退格和换行复用 `KeyboardIconKey`；输入法切换、剪贴板、撤销与重做复用 `KeyboardShortcutButton`，颜色和激活底块与普通工具栏、底栏共用更新通道。仅显示图标的按钮仍保留无障碍名称。

### 共用几何与绘制

`TextEditPanelModel` 的四行、十横份同时驱动点击范围和分隔线。中央外框与侧栏首尾齐平；前两条水平缝对齐侧键间隙中线，文首尾上边则对齐末排侧键上边，使其与侧键等高，避免多出半个间距。中央图标对齐对应侧键的行中心，点击范围延伸至分隔线。键距随可用尺寸限幅，避免小窗口产生负尺寸。

`TextEditPanelGrid` 统一绘制圆角底面、外框和中性细线，中央按钮只绘制自身按下或选中填充。公共圆角裁剪统一约束边缘，分隔线在子视图后绘制；换肤同步更新底面、线色与填充。中央内容左右各留 6 dp，选择文字在既有字号范围内适配，避免窄浮动窗口中文字贴线。选择状态由按钮文字、强调色填充和无障碍状态表达。

### 排序兼容

共享字段 `touch_text_edit_button_order` 继续保存八个稳定身份。默认顺序按维护者确认的布局改为 `copy, cut, paste, select_all, delete, number_pad, space, select_line`；七个可见项映射左列四格及右列前三格，换行固定。显式保存的旧排列保留相对顺序，不强制重置。

Android 排序页只编辑七个可见动作，保存时替换完整排列中的可见位置，隐藏身份及其位置不变；恢复默认使用共享 Rust 的完整排列，取消不写盘。默认值、补齐旧七项文档和严格提交校验仍由共享层持有，Java 只转换身份与提交草稿。

默认排列在盘上省略。非默认排列仅在 `select_line` 位于末尾时写前七项，读盘再无损补回；它位于其他位置时写全八项。这样既不把显式旧排列误当新默认，也允许只认识七项的已发布版本读取兼容文档。经 FFI 交给宿主的快照始终包含完整八项。

### 编辑器与面板边界

方向、Shift 选择和 Ctrl+Home/End 沿用既有按键通道；复制剪切尊重编辑器菜单权限，粘贴保留既有回退，不通过读取文本绕过复制限制。中央单元格仍是独立的点击和无障碍控件；被覆盖的键列、普通工具栏和原复制预览从无障碍树隐藏，单手退出与浮动停靠仍可达。同一输入框重启保留面板与选择开关。

Android 公共 [`InputConnection`](https://developer.android.com/reference/android/view/inputmethod/InputConnection) 不提供撤销栈的只读可用性查询。标题行与普通工具栏共用 `ImeToolbar.canDispatchHistory()`：无连接或密码框禁用并淡化两个按钮，其他输入框的历史状态按未知处理，保留命令入口。发送成功不表示编辑器执行成功，不按文字是否为空、输入次数或撤销次数推测栈深；准确状态需要编辑器配合。

## Alternatives considered

- 五键侧栏、独立行边界和符号键：动作更容易发现，但挤压主要操作，采用四键侧栏并保留换行长按入口。
- 四个边界键放在方向区四角：能利用空角，但切碎方向区；精简后只保留末排文档边界，让字符移动区连续。
- 中央四排等高或全部缝对齐侧键间隙中线：规则统一，但末排比侧键多半个间距，因此末排直接对齐侧键上边。
- 中央每键各画圆角键帽：能直接复用皮肤绘制，但破坏共同底面的连续性，因此由网格画底面和线，按钮保留动作与状态。
- 固定全部侧键或将偏好改成七项：映射简单，但丢失既有定制或隐藏身份，因此只过滤展示、合并可见草稿。
- 旧排列也省字段或非默认一律写八项：前者会重排显式旧数据，后者妨碍已发布七项版本读盘，因此仅省略可无损补回的末尾选行。
- 按输入与撤销次数估计历史：无需编辑器配合，但编辑器会合并输入、保留既有历史或自行修改文本，计数会误禁用可用动作，因此只应用明确的连接和输入框限制。

## Consequences

主要编辑操作拥有更大的连续目标，顶部导航和侧栏分组稳定；代价是选行与行边界失去独立入口，自定义顺序也可能改变默认分组。八项身份和兼容写盘规则仍需保留，不能因当前只显示七项就删去隐藏数据。

布局继续使用宿主键盘高度，窄窗口的触摸舒适度不能仅靠缩字保证。公共绘制需与皮肤同步，无缝外观不能合并点击或无障碍节点；编辑器不支持的菜单动作、全文或历史状态仍不能由输入法补造。
